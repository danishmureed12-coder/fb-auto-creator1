How It Works

Simple Setup,
Powerful Execution

From installation to fully automated account creation in just a few steps.

1

Install & Setup

Download the tool, install Node.js dependencies with npm install. Place your server.js and index.html in the project folder. Run node server.js to start the automation server on port 3000.

// Quick Start
npm install
node server.js
// Open http://localhost:3000
2

Prepare Your Data

Create a CSV or TXT file with profile data: First Name, Last Name, Email, Password, Birthday (MM/DD/YYYY), Gender, Proxy (optional). Each line = one profile. The tool parses and validates everything automatically.

// Example CSV format:
John,Doe,john@mail.tm,Pass123!,01/15/1995,Male,http://proxy:8080
Jane,Smith,jane@mail.tm,Pass456!,03/22/1990,Female,socks5://user:pass@proxy:1080
3

Configure Settings

Open the web dashboard at localhost:3000. Upload your data file. Configure proxy settings, 2FA preferences, OTP fetcher endpoint, page creation settings (how many pages, custom or random names), and headless mode preference.

All settings persist between sessions
4

Launch Automation

Click "Run Auto" and watch the magic happen. The tool opens a real Chrome browser (via Puppeteer), navigates to Facebook, fills in the signup form, handles email verification via OTP, enables 2FA, extracts cookies, and creates pages — all automatically.

Real-time status updates on dashboard
5

Export & Use

Once processing completes, export all results. Each successful profile includes: Facebook UID, email, password, 2FA secret key, full cookie string, created page names, and status. Download as CSV for easy integration with other tools.

Frontend Logic

Architecture Overview

The tool runs as a local Node.js server. The frontend (index.html) communicates with the backend (server.js) via REST API endpoints. Puppeteer launches a real Chromium browser instance for each profile, executing automation steps with intelligent waits and retries instead of fixed timeouts. Proxy connections are established at the browser level using puppeteer-extra-plugin-proxy or launch arguments.

FAQ

Frequently Asked Questions

Is this tool detectable by Facebook?
The tool uses puppeteer-extra with stealth plugin to minimize detection. Combined with proxy rotation, human-like typing delays, and real browser rendering, the detection risk is significantly reduced. However, no automation tool is 100% undetectable — use responsibly.
How many profiles can I create at once?
There's no hard limit in the tool itself. You can upload hundreds of profiles in your CSV. However, each profile is processed sequentially (one at a time) to maintain stability. Batch processing speed depends on your internet connection and proxy quality.
Do I need proxies for every profile?
Proxies are optional but highly recommended. Creating multiple accounts from the same IP address increases the risk of detection and bans. For best results, use a unique proxy per profile. SOCKS5 residential proxies work best.
What email services work with the OTP fetcher?
The OTP fetcher is designed to work with API-based email services like mail.tm, guerrillamail, or any custom email API that provides inbox access. You configure the API endpoint in the settings. The tool polls the inbox for Facebook's verification code.
Can I create pages without enabling 2FA first?
Page creation triggers automatically after 2FA setup completes. The flow is: Signup → OTP Verification → 2FA Setup → Page Creation. If 2FA is disabled in settings, pages will be created after OTP verification instead. Both flows are supported.
What happens if my internet is slow?
Unlike other tools that use fixed setTimeout waits, FB ID Creator Pro uses intelligent polling with retries. Every action waits for the actual page element to appear, not a fixed timer. If a page takes 60 seconds to load, the tool waits 60 seconds. No skipped steps.
Is the tool free to use?
Yes, FB ID Creator Pro is completely free. Download the source code, install dependencies, and run it on your local machine. No license keys, no subscriptions, no hidden costs. Open source and community-driven.
